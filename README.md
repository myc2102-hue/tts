# TTS Studio — 텍스트 음성 변환

텍스트를 입력하면 자연스러운 신경망 음성으로 읽어주는 로컬 웹앱입니다.
Microsoft Edge 신경망 TTS([edge-tts](https://github.com/rany2/edge-tts))를 사용하며 API 키 없이 무료입니다.

## 설치

Python 3.10 이상이 필요합니다.

```bash
git clone <이 저장소 URL>
cd tts
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
```

## 실행

```bash
./venv/bin/python app.py
```

브라우저에서 <http://localhost:8765> 접속.

같은 네트워크(사무실/집)의 다른 사람과 공유하려면:

```bash
TTS_HOST=0.0.0.0 ./venv/bin/python app.py
# 다른 기기에서 http://<이 컴퓨터의 IP>:8765 로 접속
```

포트는 `TTS_PORT` 환경변수로 변경할 수 있습니다.

## 기능

스튜디오형 UI: 상단 바(프로젝트 관리) + 스크립트 편집 패널 + 우측 음성 설정 인스펙터 + 하단 트랜스포트 바(재생/저장/이퀄라이저).

- 여러 줄 입력: "＋ 줄 추가"로 줄을 늘리고, 줄마다 ▶ 버튼으로 개별 재생 (`Cmd+Enter`도 가능)
  - 줄 앞의 ☰ 핸들을 드래그해 순서 변경 — 놓일 위치에 표시선이 미리 나타남
- 재생/저장: "▶ 재생"과 "⬇ MP3 저장"은 체크된 줄이 있으면 그 줄만, 없으면 전체를 하나의 MP3로 합성
  - 선택된 줄이 있으면 버튼 라벨이 "▶ 선택 n줄 재생"으로 바뀌어 대상 범위를 미리 알 수 있음
- 한국어(선히·인준·현수) 포함 400여 개 음성 선택
  - Multilingual 음성(Ava, Emma, Andrew, Brian, Seraphina 등)은 한국어도 읽을 수 있음
- 스타일 프리셋: 아나운서(남/여), MZ 활기찬(남/여), 다큐 나레이션, 오디오북, 외국인 느낌(남/여)
  - 프리셋은 목소리 + 속도 + 톤 조합이며 `index.html`의 `PRESETS` 배열에서 자유롭게 추가/수정 가능
  - 사용 중인 프리셋은 스크립트 패널 배지와 인스펙터에 표시되고 프로젝트에 함께 저장됨
- 내 프리셋: "⭐ 현재 설정을 프리셋으로 저장" 버튼으로 현재 설정을 원하는 이름으로 저장
- 내 프로젝트: 상단 바에서 생성(＋)·전환(드롭다운)·이름 변경(✏️)·삭제(🗑, 두 번 확인)
  - 줄 내용/체크 상태/목소리/속도/톤/프리셋이 수정 후 0.5초 뒤 자동 저장되고, 다시 열면 마지막 프로젝트가 복원됨
  - `Cmd+S`(Windows는 `Ctrl+S`)로 즉시 저장도 가능
- 속도(-50% ~ +100%), 톤(-50Hz ~ +50Hz) 조절
- 재생 중 오디오에 실시간 반응하는 네온 이퀄라이저 (그라데이션 + 피크 캡)
- 브라우저에서 바로 재생, MP3 저장

## 데이터 저장 위치

프로젝트와 내 프리셋은 **브라우저의 localStorage**에 저장됩니다.

- 접속 주소(origin)별로 저장소가 분리됩니다. 항상 같은 주소(예: `http://localhost:8765`)로 접속하세요.
  `127.0.0.1`이나 파일 직접 열기(`file://`)는 다른 저장소를 보게 됩니다.
- `index.html`을 브라우저로 직접 열면 API 호출이 실패하므로 반드시 서버를 통해 접속해야 합니다.

## 목소리 추가에 대해

edge-tts는 Microsoft가 제공하는 음성 카탈로그 안에서만 선택할 수 있고,
완전히 새로운 목소리(음성 복제, 감정 스타일 지정)는 지원하지 않습니다.
그 이상이 필요하면: Azure Speech(유료, 한국어 음성 10여 종 추가),
ElevenLabs/Typecast(음성 복제·캐릭터 보이스), 또는 로컬 모델(F5-TTS, GPT-SoVITS 등)을 검토하세요.

## 참고

- 음성 합성은 Microsoft 서버를 통해 이루어지므로 인터넷 연결이 필요합니다.
- 사내 SSL 검사 프록시 환경을 위해 `truststore`로 시스템 인증서를 사용합니다.
- 인증 기능이 없으므로 인터넷에 그대로 공개(포트포워딩, 클라우드 배포)하는 것은 권장하지 않습니다.
  공개 배포가 필요하면 리버스 프록시에서 접속 제한(암호/IP)을 걸어주세요.
